💻 ATALHOS SUPREMOS DO VS CODE (Para arquivo .txt)
1. Edição e Escrita de Código

    Ctrl + /  (Mac: Cmd + /)
    -> Comenta ou retira o comentário da linha.
    -> Macete: Muito mais rápido que digitar as tags manualmente.

    Alt + Seta para Cima ou Baixo  (Mac: Option + Seta para Cima ou Baixo)
    -> Move a linha inteira de código para cima ou para baixo.
    -> Macete: Evita ter que ficar recortando e colando blocos.

    Shift + Alt + Seta para Cima ou Baixo  (Mac: Shift + Option + Seta para Cima ou Baixo)
    -> Duplica a linha atual para cima ou para baixo.
    -> Macete: Excelente para repetir tags ou regras CSS rápidas.

    Ctrl + Enter  (Mac: Cmd + Enter)
    -> Abre uma linha em branco abaixo, sem quebrar a linha atual.

    Ctrl + Shift + Enter  (Mac: Cmd + Shift + Enter)
    -> Abre uma linha em branco acima da linha atual.

2. Seleção e Navegação Rápida

    Alt + Clique  (Mac: Option + Clique)
    -> Cria múltiplos cursores na tela para digitar em vários lugares ao mesmo tempo.

    Ctrl + D  (Mac: Cmd + D)
    -> Seleciona a próxima palavra igual à que você selecionou.
    -> Macete: Perfeito para renomear classes repetidas de uma vez.

    Ctrl + L  (Mac: Cmd + L)
    -> Seleciona a linha inteira de uma vez.

    Ctrl + Seta para Esquerda ou Direita  (Mac: Option + Seta para Esquerda ou Direita)
    -> Pula de palavra em palavra no texto, em vez de ir letra por letra.

3. Interface e Sistema do VS Code

    Ctrl + B  (Mac: Cmd + B)
    -> Abre ou fecha a barra lateral (Explorer).
    -> Macete: Ganhe mais espaço na tela para ver o código.

    Ctrl + ' (ou Ctrl + J)  (Mac: Cmd + ' ou Cmd + J)
    -> Abre ou esconde o Terminal integrado.

    Ctrl + Shift + P  (Mac: Cmd + Shift + P)
    -> Abre a Paleta de Comandos global (para buscar qualquer função do editor).

    Ctrl + P  (Mac: Cmd + P)
    -> Busca rápida de arquivos pelo nome. Basta digitar o nome do arquivo e dar Enter.
